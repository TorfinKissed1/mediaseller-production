# Страница продакшна mediaseller.agency

Статичная вёрстка лендинга видеопродакшна: HTML, CSS и чистый JS без сборки и зависимостей.
Готовится под перенос в тему WordPress отдельным шаблоном страницы.

## Как открыть

`index.html` открывается и напрямую, но удобнее через любой статичный сервер:

```bash
python -m http.server 8124
```

Страница: http://localhost:8124. Chrome жёстко кэширует CSS и JS, после правки обновляй с Ctrl+Shift+R.
Сборки, тестов и линтеров нет.

## Карта файлов

| Файл | За что отвечает | Чего не делает |
|---|---|---|
| `index.html` | вся разметка по БЭМ, SVG-спрайт иконок в начале `<body>` | не тянет данные извне, всё содержимое прописано в разметке |
| `css/base.css` | токены в `:root`, темы, сброс, раскладка, появление при прокрутке | не описывает блоки |
| `css/blocks.css` | БЭМ-блоки; медиазапросы собраны в конце, от широких к узким | не ссылается на файлы: иконки внутри CSS только `data:`-SVG |
| `js/main.js` | меню, бегущие строки, слайдеры, лента портфолио, превью по наведению, плеер, окна, вопросы, формы | не отправляет формы и не знает путей к медиа: всё берёт из атрибутов разметки |
| `img/cases/` | постеры роликов 960×540 (вертикальные 540×960) | |
| `img/renders/` | рендеры: `<имя>.jpg` 1920 px для плеера, `<имя>-s.jpg` 960 px для карточки | |
| `img/clients/`, `img/trips/`, `img/series/` | логотипы клиентов, фото из поездок (4:3, 960 px), условные кадры схемы серии | |
| `video/` | ролики 720p H.264; `hero.mp4` фон первого экрана, `cinema.mp4` ролик на весь экран | |
| `video/preview/` | беззвучные превью на 6 секунд для наведения | |

Внешние запросы только к Google Fonts (Onest, Unbounded). Если шрифты не загрузились, срабатывает
системный запасной шрифт из `--ms-font` и `--ms-font-display`, вёрстка не ломается.

## Как устроено

**Масштаб.** Размеры в `rem`, корневой шрифт `clamp(13.78px, 1.1111vw, 21.34px)`: 16 px на 1440,
от 1240 до 1920 страница масштабируется целиком. С 1024 и ниже корень 16 px, раскладку меняют
медиазапросы 1240, 1024, 768, 480, 375, 340.

**Темы.** Цвета блоков из переменных `--c-*`, по умолчанию тёмные. Класс `theme theme--light` включает
светлую палитру внутри блока, `theme theme--dark` возвращает тёмную.

**Карточка работы `.case`** единственное место, где описан кейс. Плеер и лента читают всё из её атрибутов:

| Атрибут / элемент | Что это | Обязательно |
|---|---|---|
| `data-case` | метка карточки для скрипта | да |
| `data-title`, `data-kind` | заголовок и тип для плеера и ленты | да |
| `data-video` | ролик для плеера | да, если не рендер |
| `data-image` | большая картинка для плеера (рендеры) | вместо `data-video` |
| `data-preview` | беззвучное превью при наведении | нет |
| `data-portrait` | вертикальный ролик | нет |
| `data-review` | ролик видеоотзыва, кнопка `.case__review` | нет |
| `.case__poster` | постер в карточке и в плеере | желательно; без него плеер всё равно откроется |
| `.case__text` | подпись, она же текст под роликом в плеере | нет |

Кнопка с `data-case-open="<id>"` открывает в плеере карточку с этим `id`. Стрелки плеера листают
карточки той же `<section>`, из ленты портфолио листаются все карточки страницы.

**Слайдер.** `[data-slider]` с `.slider__track` и стрелками `[data-slider-prev]`, `[data-slider-next]`
в той же `<section>`. Один слайдер на секцию: скрипт ищет стрелки по секции.

**Лента портфолио.** Источник: скрытый `ul.showcase__source` внутри `[data-showcase]`. Скрипт раскладывает
карточки по рядам (не больше трёх) и повторяет набор, пока ряд не закроет экран, поэтому лента
бесконечная при любом числе работ. Чтобы одна работа не стояла в ряду дважды на виду, нужно
примерно по четыре карточки на ряд, то есть около 12.

**Бегущие строки `[data-marquee]`.** Набор повторяется, пока не закроет экран. Скорость задана
в CSS (`animation` у `.clients__track`, `.insight__track`) как время прохода одного набора: при
меньшем числе логотипов строка едет медленнее, это правится длительностью.

**Формы** `[data-form]` проверяют обязательные поля и показывают «Спасибо, заявка у нас». Отправки нет.

## Число элементов

Жёстких ограничений по количеству нет: каждая функция в `main.js` выходит без ошибки, если её
элементов на странице нет или их мало. Проверено на урезанной странице: одна работа в ленте,
по одной карточке в слайдерах, два логотипа, один вопрос, карточка без постера, кнопка
`data-case-open` с несуществующим `id`.

Сетки опыта (`.trust__list`), схемы серии (`.series__list`) и этапов (`.steps`) на десктопе ставят
все пункты в один ряд, на узких экранах переходят на 2 колонки или список. Ряд делится поровну,
поэтому при большом числе пунктов карточки становятся узкими: тогда стоит задать колонки явно. Условия в «Агентствам» (`.bento__side`) стоят сеткой 2×2 и переносятся.

## Перенос в WordPress

Проект переносится как шаблон страницы темы (`page-<имя>.php`) без переделки CSS и JS.

- **Пути.** Относительные `img/...` и `video/...` есть только в `index.html`. В шаблоне их заменяют
  URL из ACF или `get_template_directory_uri()`. CSS и JS путей не содержат.
- **Подключение.** `css/base.css`, `css/blocks.css`, `js/main.js` и шрифты через `wp_enqueue_style`
  и `wp_enqueue_script` (скрипт в подвал). Стили темы и плагинов на этой странице лучше снять, иначе
  они перебьют сброс из `base.css`: страница рассчитана на свой корневой шрифт.
- **Повторители ACF.** Любой повторяющийся блок выводится циклом без правок скрипта:

| Блок | Поля строки |
|---|---|
| ряды работ (AI, эфир, съёмки, вертикальные, рендеры) и лента | файл ролика, превью, постер, заголовок, тип, подпись, вертикальный, отзыв |
| клиенты | логотип, название |
| опыт агентства, этапы, схема серии, условия «Агентствам» | заголовок, текст, картинка |
| вопросы | вопрос, ответ; `id="faq-N"` и `aria-controls` из индекса цикла |
| фото из поездок, агентства бегущей строки | картинка / текст |

- **Ролик на весь экран.** Поле «связанная работа» выводит `id` карточки в `data-case-open`.
- **Превью и постеры** делаются из ролика, например ffmpeg:
  `ffmpeg -ss 2 -t 6 -i in.mp4 -an -vf scale=-2:360 -c:v libx264 -crf 28 preview.mp4` и
  `ffmpeg -ss 2 -i in.mp4 -frames:v 1 -vf scale=960:-2 poster.jpg`. Превью необязательно.
- **Формы.** Отправку подключить отдельно (admin-ajax, REST или плагин форм) с серверной проверкой,
  приманкой от ботов и лимитом отправок: сейчас проверка только в браузере.

## Что не готово

- отправка форм;
- часть текстов черновая: пункты карточек продуктов, этапы, ответы на вопросы, условия «Агентствам»;
- в `data-review` у съёмок стоит ролик самого кейса, а не отзыв.
